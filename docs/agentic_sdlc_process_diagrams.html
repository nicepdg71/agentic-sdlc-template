5. Agentic SDLC 핵심 거버넌스 4대 원칙

1. Stop on Gate
에이전트는 각 Stage 산출물이 완성되면 반드시 실행을 중단하고 인간의 명시적 승인을 요청합니다.
2. Non-Auto-Execution
인간이 승인하더라도 다음 단계 워크플로우를 자동 실행하지 않고 사람이 직접 다음 명령을 호출합니다.
3. Earliest Impacted Stage
변경 요청 시 임의 코딩을 금지하며, 영향도 분석을 통해 도출된 최초 영향 단계부터 순차 재승인합니다.
4. Upstream Preservation
영향을 받지 않은 상위 승인은 그대로 보존되며, 영향을 받은 하위 산출물만 STALE로 전환되어 갱신됩니다.
