# Workflow: Design System

1. Translate requirements into technical architecture (`ARCHITECTURE.md`).
2. Define component interactions in `DESIGN.md`.
3. Formalize data models in `DATA_MODEL.md` and contracts under `contracts/`.
4. Document architectural decisions in `docs/02-design/adr/`.
5. Complete security architecture review (`SECURITY_DESIGN.md`).
6. Produce `DESIGN_HANDOFF.json`.
