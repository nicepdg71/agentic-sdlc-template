# Agent System Configuration

## Overview
This document defines the agent ecosystem, roles, capabilities, and governance policies within this project.

## Agent Roles
- **Product Analyst Agent**: Handles project definition, requirements gathering, and traceability.
- **Architect Agent**: Responsible for high-level architecture, contracts, and data modeling.
- **Developer Agent**: Implements features according to design specs and implementation plans.
- **QA / Test Agent**: Generates test cases, executes test plans, and verifies acceptance criteria.
- **Security Agent**: Conducts security reviews, secret audits, and vulnerability assessments.
- **Release Manager Agent**: Prepares release notes, validates checklists, and manages deployment plans.
